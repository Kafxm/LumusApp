# Lumus

Lumus is a Next.js application that connects independent creators with companies looking for demonstrated technical skills.

## Run locally

Requirements: Node.js and npm.

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Important

This project is a local prototype. Accounts, profile data, and login lockout are stored in the browser's `localStorage`; this is not a production authentication or authorization system. Never use real passwords or sensitive personal data with this demo.
